## APIs

- **iGamingScraper REST API** — Token-authenticated REST API providing structured iGaming data: slot providers, slots, news articles, jobs, and regulatory entities. OpenAPI 3.0.3, cursor-paginated, ETag-friendly, with incremental sync support. (`https://i-gaming.tools/api/v1`)
- **iGaming Tools MCP Server** — Free public hosted MCP server (Streamable HTTP transport, no API key, read-only) exposing 13 tools over the same iGaming dataset: providers, slots, demos, specs, screenshots, regulators, news and jobs. Compatible with Claude, ChatGPT, Cursor, VS Code/Copilot and Claude Code. (`https://mcp.i-gaming.tools/mcp`)
