# iGaming Tools

> Machine-readable dataset of casino slots: screenshots, symbols,
> colour palettes, RTP, volatility, providers and metadata.
> REST API available for structured access.

## Catalog

- [https://i-gaming.tools/slot-games/](https://i-gaming.tools/slot-games/) — Slots catalog with verified capture data
- [https://i-gaming.tools/news/](https://i-gaming.tools/news/) — Industry news
